# Pin Model Versions at admission

Workers advertise immutable Model Versions by the canonical SHA-256 of each `ModelManifest`: Model Family, role-keyed asset hashes, ordered default LoRA selections, and sampling preset. Canonical serialization sorts asset-role keys and preserves default-LoRA order; Worker-local asset paths are not model identity. Built-in sampling defaults are 40 steps/CFG 6 for `QwenImage21` and 4 steps/CFG 1 with sigmas `[1.0, 0.965517, 0.888889, 0.679245, 0.0]` for `MinimaxH3`. Tenant APIs map Model aliases to those versions, and admission resolves the alias once and pins its version hash for every Attempt. Worker matching also checks requested image LoRA hashes and configured shape limits; estimated Model and accelerator memory remain metadata, not admission gates. Reassigning or deleting an alias does not change an existing Generation or its pinned version.
