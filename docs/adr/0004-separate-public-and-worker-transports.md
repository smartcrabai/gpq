# Separate public and Worker transports

External clients use the typed native Connect API for Generation, model catalog, and Tenant services, with HTTP Artifact upload/download and health routes. Remote-to-Worker control remains outbound bidirectional gRPC with separate Artifact-transfer RPCs; Tenant Master Keys and tenant-scoped Worker credentials remain distinct. The single `gpq` executable exposes `remote`, `worker`, and private `infer` roles, with `infer` serving only the Worker runtime boundary. SQL remains outside the RPC stack.

Schemas declare `edition = "2024"` and compile through `connectrpc-build` and Buffa using `protoc` 33 or newer into Cargo `OUT_DIR`. CI runs Buf lint and breaking-change comparison without using Buf for code generation; removed fields reserve their names and numbers, and breaking APIs move from the `v1` package to a new major package. Native Generation, Catalog, and Tenant services use Connect binary or JSON; Worker enrollment and its bidirectional control Session require gRPC, while separate Worker transfer RPCs carry Artifact chunks so bulk traffic cannot block heartbeats and cancellation.
