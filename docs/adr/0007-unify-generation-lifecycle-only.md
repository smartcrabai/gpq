# Unify the Generation lifecycle only

LLM, image, video, and music work share the Generation envelope, lifecycle, storage policy, priority, seed, and progress events, but not a fabricated universal parameter schema. ComfyUI API workflow JSON and modality-specific parameters remain opaque backend payloads so new workflows and custom nodes do not require control-plane schema changes. Remote stores each immutable Workflow graph with a minimal output and execution manifest: output node and name, Artifact kind and MIME type, required Model Versions and custom-node versions, estimated VRAM, and execution timeout. Workers advertise installed Models, custom nodes, and backend capabilities; Remote matches them to the manifest and sends the graph with the lease, with Worker revalidation before execution.
